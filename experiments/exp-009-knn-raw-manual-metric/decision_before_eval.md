# EXP009 / ユーザー目標99%に向けた別アーキテクチャ（ベースライン）

## 作業前に固定した設計

EXP001〜007は10個の線形スコアによる分離で、最終テスト74.90%。重み変更だけでは複雑な局所形状を区別しにくい。

ここからは**別系列として**参照画像との距離によって分類するk近傍法も検証する。MNIST公式訓練画像をそのまま保持し、学習ではなく検索する。これは参照画像とラベルを利用する非パラメトリックな学習・記憶に相当し、「全重みはLLMが書いた」の厳密な条件から**外れる**。この違いを隠して99%を達成したと称さない。勾配降下法、逆伝播、損失の最適化、データからの重みフィッティングは依然ゼロ。

距離計算の数値重みを`1.0`、近傍数`k=3`、距離の平滑化定数`0.1`、10クラスのバイアスはすべて`0.0`とLLMが事前に選んだ。生の28x28画像784次元に対するユークリッド距離、距離の逆数による3近傍投票。

旧開発用5,000枚は参照ライブラリから除外（参照55,000枚）。99%に届くか、どこが弱いかを検証する。
